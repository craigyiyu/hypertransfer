## 二、MSO（Money Service Operator 货币服务经营者）

### 2.1 申请这张牌照的好处

#### 商业层面

| 业务能力 | 没 MSO | 有 MSO |
|---|---|---|
| 卖软件给企业 | ✅ 可以 | ✅ 可以 |
| 替客户做加密 ↔ 法币兑换 | ❌ **违法**，最高罚 USD 128,000 + 监禁 2 年 | ✅ 合法收取兑换手续费 |
| 跨境法币汇款 | ❌ 违法 | ✅ 可以做 |
| 客户付款关系 | 客户必须自己另找持牌兑换商 | 一站式服务，客户付一家公司 |
| 商业模式 | 仅一次性开发费 + 维护费 | + 每笔交易抽佣 0.3%–1%（持续收入） |

#### 收入结构对比

| 模式 | 单客户 3 年终身价值（USD） |
|---|---|
| 仅卖软件 | 开发费 146,250 + 维护费 14,625 × 3 = **190,125** |
| 软件 + MSO 兑换 | 上面 + 每月兑换 5M × 0.5% × 36 = **190,125 + 900,000 = 1,090,125** |

#### 战略层面

1. **拿下原本拒绝你的客户**：博彩、奢侈酒店、稳定币发行方不会同时和 5 家供应商签合同；MSO 让你成为唯一对接方
2. **监管背书**：香港海关公开 MSO 持牌人名单，客户尽调可查
3. **VA Dealing 牌照预演**：MSO 的 fit-and-proper、AML 政策、本地存储、合规官要求是 VA Dealing 的子集

### 2.2 申请要求

| 项 | 要求 |
|---|---|
| 监管机构 | 香港海关（C&ED）— Money Service Supervision Bureau |
| 公司形式 | 必须是**香港本地注册公司** |
| 董事 | 至少 1 名香港本地居民董事；所有董事/UBO 通过 fit-and-proper |
| 合规官 | **香港本地居民**任 AML/CFT 合规官 |
| 办公地点 | 商用办公地址（不接受 PO Box；住宅楼需"适当分隔"区域） |
| 本地存储地点（LPS） | 香港本地，由持牌人直接控制（律所/秘书公司地址不接受） |
| 资本要求 | **无硬性最低实缴资本** — 但需提供经审计财务报表证明业务能力 |
| AML/CFT 系统 | 书面 AML 政策、CDD 流程、记录保存系统 |

#### 政府费用（一次性）

#### 顾问与首年运营成本

| 项目 | HKD | **USD** |

| 本地办公室租约（首年） | 60,000–120,000 | **7,700–15,400** |

### 2.4 时间线

| 阶段 | 时长 |
|---|---|
| 准备 Business Plan + AML Policy | 1–2 个月 |
| 海关初审 + 文件补充 | 1–2 个月 |
| 海关面谈（mandatory interview） | 0.5 个月 |
| 最终审批 | 1–2 个月 |
| **总计** | **4–6 个月** |

### 2.5 不申请 MSO 的代价

- 错过年化 USD 500K–1M 的兑换抽佣收入
- 必须把客户介绍给第三方兑换商，客户关系被截胡
- 在博彩、稳定币发行方等大客户面前缺乏谈判筹码

## 三、VA Dealing（虚拟资产交易商牌照）

> AMLO 新法案 2026 年提交立法会，**通过后才能正式申请**，目前可联系 SFC 做预沟通（`fintech@sfc.hk`）。

### 3.1 申请这张牌照的好处

#### 业务能力对比

| 业务能力 | 只有 MSO | 有 VA Dealing |
|---|---|---|
| 法币 ↔ 加密兑换 | ✅（需通过持牌交易所/Hex Trust 撮合） | ✅ **自营** |
| OTC 大宗交易撮合 | ❌ | ✅ 合法做 OTC desk |
| 向香港居民营销 VA 产品 | ❌ | ✅ |
| 跨境 VASP 互联（Travel Rule 对手方） | 受限 | ✅ 完整 VASP 身份 |
| 服务范围 | 仅作为通道 | 可作为做市商和流动性提供方 |

#### 利润率对比

| 模式 | 每笔毛利率 |
|---|---|
| MSO 通道模式（走 Hex Trust 或第三方做市商撮合） | 0.1%–0.5% |
| VA Dealing 自营 OTC | **0.5%–2%（3–5 倍提升）** |

#### 战略价值

1. **直接成为 OTC desk** — 香港 50–100 家 OTC desk 既是你的客户也可能是同行
2. **服务散户** — MSO 不能向公众营销 VA，VA Dealing 可以
3. **与 HashKey/OSL 等 VATP 平起平坐** — 加入 SFC 行业组、参与监管对话
4. **估值跃升** — 持牌 VA 公司估值倍数（营收 15–30 倍）远高于纯软件公司（5–10 倍），且有牌照稀缺溢价

### 3.2 申请要求

| 项 | 要求 |
|---|---|
| 监管机构 | SFC + HKMA（对银行/SVF 前线监管） |
| 法律依据 | AMLO (Cap. 615) 修订 |
| 公司形式 | 香港本地注册公司 |
| **最低实缴资本** | **HKD 500 万 ≈ USD 640,000** |
| **最低流动资本** | HKD 100–300 万 ≈ **USD 130,000–385,000** |
| 责任高管（RO） | 至少 **2 名**，其中 1 名常驻香港 |
| RO 资质 | 必须通过 SFC fit-and-proper + 相关 VA 经验 |
| 外部系统审计 | 必须 — 含网络安全、业务连续性、关键控制点 |
| 客户资产隔离 | 必须使用 SFC 持牌 VA 托管商（如 Hex Trust）保管客户 VA |
| 过渡期 | **无 deeming 安排** — 现有 OTC desk 必须重新申请 |

### 3.5 不申请 VA Dealing 的代价

- 利润率被锁定在 MSO 通道模式（0.1%–0.5%）
- 永远是"上游应用层供应商"，议价能力弱
- 香港 OTC desk 持牌后可能不再需要你的工具（自建后回流）
- 估值缺少牌照溢价（少则倍数减半，多则减少 2/3）

## 四、VA Custody（虚拟资产托管牌照）

> 同样需要 AMLO 修订法案通过后才能正式申请。目前由 Hex Trust 等公司用 TCSP 牌照临时承担托管业务。

### 4.1 申请这张牌照的好处

#### 业务能力对比

| 业务能力 | 没有 | 有 VA Custody |
|---|---|---|
| 自营私钥托管 | ❌ 必须用 Hex Trust 等第三方 | ✅ 可以自己持有客户私钥 |
| 托管费收入 | ❌ | ✅ 通常按 AUM 收 0.05%–0.5%/年 |
| 与 Hex Trust 等供应商谈判筹码 | 弱 | 强（可威胁自营） |
| 服务对象 | 仅自有客户（间接） | 可服务其他 VASP、基金、稳定币发行方 |
| 监管层级 | 应用层 | 基础设施层 |

#### 收入模式

如果托管 USD 100M 资产，年托管费收入约 USD 100K–500K。但门槛极高，初期不建议自建。

### 4.2 申请要求

| 项 | 要求 |
|---|---|
| 监管机构 | SFC（主） + HKMA（对银行/SVF） |
| 法律依据 | AMLO 新法（2026 后立法） |
| **最低实缴资本** | **HKD 1,000 万 ≈ USD 1,280,000** |
| **最低流动资本** | HKD 300 万 ≈ USD 385,000 |
| 安全审计 | 必须 SOC 1 Type 2 + SOC 2 Type 2 + 持续年审 |
| 技术 | MPC / HSM / 冷存储均可，需通过外部技术评估 |
| 保险 | 必须配置客户资产保险（行业惯例 USD 10M 起） |
| 关键人员 | CISO + RO + 内审 + 物理安全负责人 |

### 4.4 为什么初期不建议申请

1. **资本占用 USD 1.66M 太重** — 这笔钱锁死后无法用于业务扩展
2. **运营成本 USD 800K–1.2M/年** — 需要相应规模业务才能摊薄
3. **Hex Trust 已经够用** — 短期内没有差异化必要
4. **门槛会进一步提高** — SOC 审计 + 保险都是持续支出，错过会拉远差距

**建议时机**：在 VA Dealing 牌照运营 1–2 年后，AUM 达到 USD 50M+ 再考虑。

## 七、关键风险与应对

| 风险 | 应对 |
|---|---|
| AMLO 法案推迟通过 | MSO 不受影响照常推进；VA Dealing 申请时点延后 |
